# 디자인 시스템 고도화

## 대상과 방향

한국어 콘텐츠 제작자가 프로젝트를 찾고, 카드뉴스를 편집하고, 결과물을 검토하는 작업 도구.
다크 캔버스와 라임 액션은 유지한다. 사진과 편집 타이포그래피가 결과물의 개성을 담당하고,
도구는 낮은 대비의 표면·정밀한 간격·명확한 상태로 이를 받친다.

팔레트: canvas #0a0a0b, panel #151719, raised #1a1d1f, ink #edefef,
secondary #a8aeaf, action #d1fe17. 기존 토큰 값을 보존하고 의미 기반 별칭을 추가한다.
UI는 Pretendard, editorial 제목은 Noto Serif KR, 수치는 Pretendard tabular.

선택한 특징: 사진이 중심이 되는 슬라이드와 작은 인쇄물 같은 머리말·꼬리말.
기본/에디토리얼/임팩트/소프트는 색상뿐 아니라 여백과 제목 처리에도 차이를 둔다.

```
프로젝트: 제목 + 만들기 → 검색/상태 필터 → 실제 표지와 덱 미리보기 → 빈 상태
편집기:   프로젝트 헤더 → [선택 가능한 스토리보드 | 슬라이드 + 속성] → 진행 상태
슬라이드: 대표 결과물 + 스타일/규격 선택 → 템플릿별 비교 → 확장 템플릿
```

## 기존 화면 검토

1. `01-slides-before.png`: 토큰 일관성은 좋지만 도형 이미지가 반복되어 결과물의 질감을 판단하기 어렵다. 네 프리셋의 구조가 동일하다. 사진 자산, 구도 변형, 명확한 타입 위계가 필요하다.
2. `02-projects-before.png`: 제목과 상태는 있으나 1440px 고정 폭 때문에 주요 콘텐츠가 잘린다. 검색·빈 결과·상태 필터가 없다.
3. `03-editor-before.png`: 왼쪽 목록이 화면을 차지해 오른쪽 캔버스를 볼 수 없다. 선택·페이지 이동이 빈 콜백이다. 작업 영역을 컨테이너 너비에 맞추고 선택과 미리보기를 연결한다.

스크린샷만으로 접근성 적합성을 보장하지 않는다. 키보드 조작과 상태 의미는 테스트 및 브라우저에서 별도 확인한다.

## 선정한 구성 요소

| 층       | 구현                                                                         | 용도                                              |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------------------- |
| 토큰     | surface/text/border 의미 별칭, 큰 제목·여백·focus 토큰                       | 제품 확장 시 일관된 선택                          |
| 기본     | SearchField, StatusBadge, Progress, EmptyState, Pagination, InspectorSection | 탐색·생성·오류 복구·편집 속성                     |
| 조립     | AssetCard, TimelineClip                                                      | 에셋 선택과 향후 릴스 타임라인의 최소 재사용 단위 |
| 슬라이드 | full/split/inset 구도, MetricSlide, CompareSlide                             | 기존 5종과 비교·숫자 중심 콘텐츠                  |
| 화면     | 검색/필터, 선택/페이지 이동, 스타일/레이아웃, 휴대폰 넘기기                  | 검토 가능한 인터랙티브 쇼케이스                   |

다음 확장 경계: 에셋 업로드/서버 저장, 릴스 시간 편집/재생 엔진, 브랜드 키트 저장,
계정·결제·실제 생성·PNG/ZIP 렌더러는 디자인 컴포넌트 밖의 서비스 책임이다.
해당 기능이 연결되지 않은 동작은 쇼케이스에서 명시한다.

## 호환성

기존 스튜디오 파셜과 legacy 토큰은 원본 parity를 유지한다. 새 컴포넌트 및 refinement
층까지 포함한 최종 CSS가 기존 앱 화면과 픽셀 단위로 같다는 의미는 아니다.
Next 앱 통합과 외부 배포는 이번 디자인 시스템 작업에 포함하지 않는다.

## 전체 구성 요소 검토와 채택 기준

| 기존 영역   | 구성 요소                                                      | 결정                                                                            |
| ----------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 액션        | Button, IconButton, Chip, Pill                                 | 유지. 액션 위계와 표면을 정리하고 비활성 링크의 이동을 차단. 키보드 focus 추가  |
| 입력        | Field, Input, Textarea, OptionList, Slider, Stepper, Switch    | 기존 API 유지. 편집기의 controlled 상태에 연결하고 작은 화면에서 세로 배치      |
| 탐색        | Segment, Popover/Menu                                          | 유지. Segment 측정 시 불필요한 상태 갱신 방지와 빈 목록 처리. 방향키 이동 검증  |
| 상태        | Alert, UndoBar, Skeleton, Spinner, Tooltip, Kbd                | 유지. 반복 생성/알림/대기 UI에 사용. reduced-motion 공통 규칙 추가              |
| 메타 정보   | Avatar, CreditBadge, Tag, Thumb                                | 유지. 계정/상태/썸네일에 사용하고 표지 이미지는 실제 SlideFrame으로 조립        |
| 작업 구조   | TopBar, ProjectHeader, BriefBar, ActionStrip                   | 유지. 실제 페이지 링크와 미리보기 동작에 연결                                   |
| 콘텐츠 조립 | ProjectCard, StoryboardRow, CanvasPanel, FormatCard, StyleCard | 표지 슬롯·속성 슬롯을 추가하고 프로젝트 탐색/슬라이드 선택/캔버스의 관계를 개선 |

기본 컴포넌트는 30개 폴더, 조립 컴포넌트는 11개 폴더다. Popover 폴더의 Menu 등 보조 export는 별도 개수로 중복 계산하지 않았다.

### 새 컴포넌트 계약

| 구성 요소        | 사용 시점                         | 상태/접근성                                      |
| ---------------- | --------------------------------- | ------------------------------------------------ |
| SearchField      | 프로젝트·에셋 탐색                | controlled 입력, 명시적 label, 지우기 버튼       |
| StatusBadge      | 초안·완료·경고·오류·진행·미리보기 | 색과 문구를 함께 사용                            |
| Progress         | 파일 처리·생성 작업               | determinate/indeterminate, progressbar 이름과 값 |
| EmptyState       | 검색 결과 없음·최초 사용          | 제목, 설명, 복구 액션 슬롯                       |
| Pagination       | 프로젝트·슬라이드 이동            | 페이지 범위 보정, 이전/다음 비활성 상태          |
| InspectorSection | 편집 속성 그룹                    | native details/summary로 키보드 열기·닫기        |
| AssetCard        | 사진·업로드 자산 선택             | 버튼과 aria-pressed, 썸네일 및 메타 정보         |
| TimelineClip     | 릴스 장면 선택의 기반             | 버튼과 aria-pressed. 시간 문자열은 호출 측 제공  |

### 다음 확장 우선순위

1. **자산 관리**: AssetCard + SearchField + EmptyState를 기반으로 업로드 드롭존, 파일 검증, 오류/재시도, 서버 페이지네이션을 연결한다. 실제 저장소 계약이 정해질 때 파일 상태 모델을 확정한다.
2. **브랜드 키트**: InspectorSection 안에 색·서체·로고 선택기를 구성한다. 저장/권한/브랜드별 토큰 덮어쓰기 정책이 먼저 필요하다.
3. **릴스 편집**: TimelineClip을 트랙·플레이헤드·트림 핸들로 확장한다. 재생 엔진, 시간 단위, 키보드 조작 계약을 먼저 확정한다.
4. **실제 내보내기**: 현재 JSON 내보내기 이후, 폰트와 이미지 로드 완료를 보장하는 PNG/ZIP 렌더러 및 진행/재시도를 연결한다.

## 구현 결과

- 토큰 **71 → 89**, 기본 컴포넌트 **24 → 30**, 조립 컴포넌트 **9 → 11**.
- 슬라이드 **5 → 7종**: Cover, Body, List, Quote, CTA에 Metric, Compare 추가.
- 4개 프리셋에 타이포그래피·여백·장식 차이를 부여하고 full/split/inset 구도를 지원한다.
- 이미지 2종을 생성하고 로컬 최적화 JPEG로 적용했다. [출처](../assets/README.md).
- 프로젝트 검색/필터/빈 결과 복구/페이지 이동, 편집기 제목·본문 수정과 장 추가/복제/삭제, 스타일·구도·사진 선택, 휴대폰 페이지/좋아요 상태가 동작한다.
- 서비스가 필요한 버튼은 미연결 상태를 표시한다. 저장 상태는 로컬 미리보기이며 새로고침하면 초기화된다.
