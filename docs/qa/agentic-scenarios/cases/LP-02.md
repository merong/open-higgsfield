# LP-02 — 가격 없이 시작하는 지역 청소 상담

형식 `landing` / 한 문장 / 주 검증: 최소 입력·미제공 사실 생략. 공통 [실행 지침](../runner-guide.md)과 C1~C5를 적용한다. 가상 서비스이며 아직 실행하지 않았다.

## 최초 입력과 사실

> 마포구에서 이사 전후 원룸 청소를 상담받는 ‘맑은방’ 랜딩페이지를 만들어줘.

확정 사실은 브랜드, 마포구, 원룸 이사 전후 청소, 상담 목적뿐이다. 가격·서비스 보장·전화번호·직원 수·장비·운영 시간·작업 사진·고객 후기는 없다. 예상 독자는 이사 전후 원룸 거주자다. 폰트/색/페이지 길이는 AI가 정한다.

## 사용자 턴과 체크

1. 최초 입력 후 **L1:** 추가 가격/브랜딩 폼 없이 초안을 진행하는지 본다. 현행 필수 승인은 기록하되 목표 UX 통과로 간주하지 않는다. 가격 미제공을 이유로 상담 페이지 전체를 막으면 차이로 남긴다.
2. 초안 후:
   > 너무 대형 청소업체 같아. 첫 소개 문구만 혼자 이사를 준비하는 사람이 부담 없이 상담하는 느낌으로 바꿔줘.

   **L2:** 톤과 해당 소개만 변경. 실제 소규모 직원 수, 1인 운영, 최저가, 당일 보장 같은 새 사실을 추가하면 실패다.
3. 수정 결과 후:
   > 전후 비교 사진은 쓰지 말고, 밝고 정돈된 원룸 분위기의 연출 이미지 한 장만 사용해줘. 실제 시공 사례처럼 소개하지 마.

   **L3:** 이미지 총 1장이라는 사용자 제약을 계획→실제 배치까지 확인한다. 생성이 필요하면 실행 설정의 허용 범위 내에서 수행한다. 기존 적합 자산을 재사용해도 된다. '우리 작업 결과'로 오인시키는 캡션은 없다.
4. 저장·재접속 후 모바일에서 상담 CTA와 연출 표시를 확인한다.

## 질문 답변과 이미지 분기

- 비용/연락처 질문: `아직 정하지 않았어요. 가격과 연락처는 빼고 상담 안내 초안으로 진행해 주세요.`
- 가상 후기/보장 선택 질문: `후기나 보장은 제공하지 않았으니 넣지 마세요.`
- 분위기 이미지가 여전히 부적절한 경우에만 추가 턴: `지금 이미지는 고급 아파트처럼 보여. 작은 원룸 공간으로 바꾸되 이미지 수는 한 장으로 유지해줘.`
- 해당 분기를 썼다면 baseline/candidate에도 같은 분기를 적용하고 변경 이유와 재생성 수를 기록한다. 실제 결과가 작은 원룸이면 결함을 꾸며내지 않는다.

## 완료와 증거

L1~L3·C1~C5, 허위 가격/후기/실적 없음, 서비스 지역과 목적 보존, 마지막 이미지 1장, 상담 URL 미설정 상태의 정직한 표시. 이미지의 내용·비율·실제 픽셀·모바일 표시를 대조한다. 질문/승인 수와 수정 범위, 전후 이미지 event ID를 남긴다. `intent`, `effort`, `image_fit` 평가. 대응 W01·W02·W03.
