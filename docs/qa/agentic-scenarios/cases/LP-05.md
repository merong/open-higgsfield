# LP-05 — 인테리어 상담의 공간 이미지 배치

형식 `landing` / 설명+사진 / 주 검증: 원본 사진 활용·크기 의도·대상 한정 수정. 공통 [실행 지침](../runner-guide.md)과 C1~C5 적용. 가상 서비스이며 아직 실행하지 않았다.

## 사진 준비와 최초 입력

[사진 준비 계약](../fixtures/README.md)의 같은 공간 전체 사진 A와 수납 디테일 B를 순서대로 첨부한다. 원본은 실제 사용 권한이 있는 자료이며 본 패키지에는 없다. 없으면 `blocked_fixture`. 이미지에 없는 시공 이력·비용은 사실로 주지 않는다.

> 작은 집의 수납과 동선을 상담하는 ‘사이공간’ 소개 랜딩페이지를 만들어줘. 첨부한 전체 공간 사진과 수납 디테일 사진을 참고해줘.

확정: 상담 서비스, 작은 집, 수납/동선 중심. 사진은 참고 자료이며 업체의 실제 시공 실적이라고 주어지지 않았다. 가격·면허/자격·시공 보증·전후 비교는 없다.

## 사용자 턴과 체크

1. 초안의 **L1:** 전체/디테일 두 자산의 역할과 실제 전달 여부를 확인한다. 대표 자산 선택이 바뀌면 이유와 mapping을 기록한다. 멋진 새 실내를 생성했다는 이유로 제공한 공간 참고를 모두 버리면 의도 미충족이다.
2. 사진 A가 쓰인 섹션을 선택하고:
   > 이 전체 공간 사진을 더 크게 보여줘. 공간 양끝이 잘리지 않게 하고 문구는 유지해줘.

   **L2:** 표시 크기·레이아웃을 우선 판단하고 원본 비율과 가독성을 대조한다. 흐려짐/공간 잘림으로 실패한 확대를 완료로 표시하면 실패다. 원본으로 충족한 경우 이미지 생성 호출은 0회.
3. 사진 B의 영역 코멘트 기능이 있으면 수납 가구를 지정하고, 없으면 해당 기능을 `unsupported`로 기록한 뒤 텍스트 경로를 별도 항목으로 수행:
   > 이 부분이 수납 설명과 연결되도록 바로 아래 설명만 바꿔줘. 사진 자체와 다른 문구는 그대로 둬.

   **L3:** 대상 사진-설명 연결, 문구 최소 수정, 자산 보존. 영역 좌표/slot/현재 버전이 연결됐는지 기록한다. 일반 텍스트 수정 성공으로 영역 코멘트 통과를 대체하지 않는다.
4. 저장·재접속 후 데스크톱/모바일에서 전체 공간 경계와 설명 대응을 다시 확인한다.

## 질문과 완료

- 시공 실적 질문: `참고 사진일 뿐 이 업체의 시공 실적은 아니에요. 그렇게 소개하지 마세요.`
- 단순 확대가 화질을 충족하지 못해 판단이 필요할 때: `공간이 달라 보이는 새 이미지는 만들지 말고, 원본이 선명하게 보이는 범위로 배치해 주세요.`
- 이미지 수는 두 사진이 수행하는 역할을 기준으로 설명한다. 불필요한 분위기 이미지 추가를 의무화하지 않는다.

L1~L3·C1~C5를 항목별 판정하고, 영역 기능 미지원은 남긴다. 원본 해시·AI 입력 연결·생성/재사용 구분·표시 크기·해상도·크롭·변경 전후 slot/asset ID와 모바일 캡처를 남긴다. `image_fit`, `visual`, `effort` 평가. 대응 W03·W04·W05.
