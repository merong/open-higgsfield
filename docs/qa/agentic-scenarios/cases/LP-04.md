# LP-04 — 체험 행사 일정 수정과 재접속

형식 `landing` / 한 문장 / 주 검증: 날짜·모집 조건, 상태 보존. 공통 [실행 지침](../runner-guide.md)과 C1~C5 적용. 가상 행사이며 아직 실행하지 않았다.

## 최초 입력과 사실

> 2030년 5월 18일 오후 2시 서울 연남동에서 열리는 성인 대상 ‘종이로 쉬는 토요일’ 90분 종이 콜라주 체험의 참가 신청 안내 랜딩페이지를 만들어줘.

시간·동네·대상·활동·소요 시간만 확정됐다. 인원·주소·가격·강사·사진·신청 URL은 없다. 고정된 미래 날짜는 테스트 자료이며 실제 모집 행사가 아니다. 실행 날짜가 2030년 이후라면 fixture를 새 suite 버전으로 바꾸고 날짜를 몰래 치환하지 않는다.

## 사용자 턴과 체크

1. 최초 초안의 **L1:** 행사 소개→누구를 위한 체험→일정→신청 안내가 보이고 확정 날짜/90분이 동일해야 한다. 초보 가능·재료 제공은 아직 사실이 아니므로 단정하지 않는다. 문의처·잔여석·마감 임박을 만들면 실패다.
2. 초안 표시 직후 새로고침한다. 사용자 턴 없이 **L2:** 동일 프로젝트·초안·기획을 복원하고 이미 완료한 유료 작업을 다시 요청하지 않아야 한다. 폴링 조회는 새 생성 호출과 구분한다.
3. 재접속 후:
   > 시작 시간을 오후 3시로 바꾸고, 준비물은 필요 없고 재료는 현장에서 제공한다는 안내를 추가해줘. 날짜와 90분은 그대로야.

   **L3:** 여기서 처음 주어진 재료 제공 사실만 추가한다. 모든 일정 표기의 시간은 3시로 일치해야 한다. 2시가 남거나 날짜/소요 시간이 바뀌면 실패다.
4. 다음 결과 후:
   > 첫 화면 이미지가 있다면 모바일에서도 종이 작업 장면이 잘 보이게 배치해줘. 문구와 일정은 바꾸지 마.

   **L4:** 원본 배치/크롭으로 충족하면 재생성 없이 변경. 이미지가 없으면 이 항목은 `not_applicable`이며 이미지를 생성해 분기 조건을 만들지 않는다. 손/종이 작업이 잘리는지 실제 390px에서 검사한다.

## 이미지·질문·완료

행사 분위기 이미지는 연출이다. 실제 참가자 사진·후기처럼 소개하지 않는다. 신청 URL/가격 질문에는 `아직 없으니 제외하고 신청 안내 초안으로 두세요.`만 답한다. 역할에 필요하지 않은 사진을 FAQ마다 생성하지 않도록 계획 이유를 확인한다.

L1~L4와 C1~C5(조건 없는 항목만 필수), 보호 날짜/대상/시간, 수정 직전·직후 문서, 재접속 전후 생성 호출 ID, 모바일 캡처를 기록한다. `factuality`, `visual`, `effort` 평가. 대응 W02·W06·W08.
