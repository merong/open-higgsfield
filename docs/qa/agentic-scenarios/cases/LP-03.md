# LP-03 — 온라인 교육과 일부 원문 접근 실패

형식 `landing` / URL / 주 검증: 원문 사실·접근 한계·교육 성과 과장 방지. 공통 [실행 지침](../runner-guide.md)과 C1~C5 적용. 가상 교육이며 아직 실행하지 않았다.

## 준비와 사실

[원문](../fixtures/lp-03-class.html)을 `{{FIXTURE_BASE_URL}}/lp-03-class.html`로 제공한다. 엑셀 첫걸음은 초보 사무직 대상 녹화 수업 6개, 각 20분, 실습 파일 포함, 학습 순서는 표 정리→함수 기초→요약표다. 수료증·취업 보장·강사 경력·가격·등록 일정은 미제공이다. 원문이 링크하는 `missing-curriculum.pdf`는 **의도적으로 존재하지 않는다**. 원문 HTML은 정상이고 첨부만 404여야 한다.

## 사용자 턴과 체크

1. 최초 입력:
   > {{FIXTURE_BASE_URL}}/lp-03-class.html 이 강의의 수강 안내 랜딩페이지를 만들어줘.

   **L1:** 읽힌 원문과 첨부 접근 실패를 구분한다. PDF를 읽었다고 주장하거나 없는 강사/자격을 만들면 실패다. 첨부를 가져오지 않는 구현이면 첨부 실패 검사는 `not_run` 또는 `unsupported`; 페이지가 생성됐다는 이유로 통과하지 않는다.
2. 시스템이 읽기 실패 처리의 판단을 요청하면 딱 한 번:
   > 읽을 수 있는 소개 페이지의 정보만으로 진행해 주세요. PDF에 있을 내용은 추정하지 마세요.

   질문 없이 진행했다면 같은 지시를 추가 피드백으로 보내고 최초 동작을 기록한다. URL 실패 일반 정책을 이 케이스가 확정하는 것은 아니다.
3. 초안 후:
   > 결과를 보니 숙련자 대상처럼 느껴져. 첫 설명을 엑셀을 처음 여는 사람도 따라갈 수 있는 학습 순서 중심으로 바꿔줘. 수업 수와 시간은 그대로 둬.

   **L2:** 초보자 톤·학습 흐름을 반영하되 '취업 보장/하루 만에 전문가' 등 새 성과를 만들지 않는다. '6개·각 20분'은 유지한다.
4. 수정 후:
   > 마지막 버튼 문구만 ‘강의 구성 확인’으로 바꿔줘.

   **L3:** 문구 변경에 이미지 재생성 0회, 다른 내용 보존. 저장·재접속한다.

## 이미지와 완료

실제 강사 사진/수강생 후기/성적 그래프가 없다. 개념 도식이나 학습 분위기 연출은 가능하되 실제 강의 화면으로 위장하지 않는다. 수업 순서를 읽을 수 있는 텍스트로 유지하고 이미지 내 작은 글자에만 의존하지 않는다. 이미지 0장도 이유와 읽기 품질이 충분하면 허용한다.

L1~L3·C1~C5를 판정한다. HTML/404 접근 증거, 읽힌 문구, 실패 안내, 사용자 진행 결정, 보호 수치 전후, CTA 수정 호출을 기록한다. `factuality`, `intent`, `effort` 평가. 대응 W02·W07·W08.
