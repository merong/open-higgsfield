## 제공 기능

- 시작 화면의 사진 갤러리: 1~6장, 다중 선택·드롭 처리, 큰 미리보기, 썸네일, 대표 지정, X 제외. 원본은 라이브러리에 남습니다.
- 사진과 사용자 조건을 함께 분석해 제작 프롬프트 및 원본별 컷 흐름 추천. 명시적으로 적용한 뒤 편집할 수 있습니다. 사진만으로 바로 컷 제작도 가능합니다.
- 실제 사진을 의도 분석·기획·수정 모델에 전달하고 컷에 소유권을 확인한 원본 에셋을 연결합니다. 새로고침·후속 제작에도 사진 목록을 보존합니다.
- 승인한 컷에서 원본 사진과 움직임 프롬프트를 수정할 수 있습니다. 이미지 기반 영상 생성에는 원본의 세로 입력 사본과 컷 프롬프트를 함께 사용합니다. 영상 재생성 때도 원본 연결을 유지합니다.
- Higgsfield 공식 서명 업로드 URL 발급 → 자격증명 없는 파일 PUT → Kling 3.0 Turbo image-to-video 접수. 원본 파일은 변경하지 않고 전체 사진을 담은 720×1280 사본을 사용합니다. 가로 사진은 여백이 생길 수 있습니다.
- 사진 전달이 실패하면 영상 요청·크레딧 차감 없이 실패를 표시합니다. 텍스트 영상으로 자동 대체하지 않습니다. 영상 잔액 50 초과·컷 승인·샘플 승인·중복 요청 방지 규칙을 유지합니다.

## 실제 브라우저 및 모델 확인

- 테스트 이미지: `fern-house.webp`, `greenhouse.webp` 두 장.

- 추천을 적용하고 15초 제작을 요청했습니다. 5초씩 3컷, 원본1 → 원본2 → 원본1, 개별 영상 프롬프트가 생성됐습니다.
- 컷 승인과 새로고침 복원을 확인했습니다. 모든 컷은 사진 에셋이 연결되어 있고 원본 선택 메뉴가 표시됩니다.
