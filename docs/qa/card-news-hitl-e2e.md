# 사용자 참여형 카드뉴스 E2E

검증일: 2026-09-20. 로컬 `127.0.0.1:3000`, 실제 등록된 OpenAI GPT-5.6 Terra / low 및 Higgsfield Soul 2 사용. 키는 출력·문서에 저장하지 않았다.

## 검증한 사용자 흐름

1. “초보자가 키우기 좋은 식물로 인스타 카드뉴스 만들어줘.” 입력.
2. 목적 질문에서 정보 전달·저장 선택. 질문 대기 중 새로고침해도 동일 질문을 복원했다. 독자는 AI 추정, 목적은 사용자 확정, 5장은 기본값으로 표시됐다.
3. 웹 검색으로 출처 5개 확보 → 장별 역할/문구 기획 5장 표시 → 사용자 승인.
4. 동일 내용의 실제 표지 디자인 3개 비교. 별도 비용 표시 버튼으로 이미지 생성 → 부드러운 이야기 선택 → 본문 작성·검수·보정.
5. 3장만 짧게 수정 요청. 추가 검수·보정 후 1·2·4·5장의 JSON 전체(문구/미디어/구도)가 정확히 동일함을 서버에서 비교했다.
6. 파일 선택기로 프로젝트의 `fern-house.webp`를 3장에 업로드해 적용 확인. 검증 목적의 이 사진은 이전 버전 복원으로 제거하고 검수된 카드 문서로 되돌렸다.
7. 실제 렌더러에서 5장 PNG 생성 → ZIP 업로드 → 서버 내용·버전·규격·PNG 디코딩 검증 → `completed` 및 개별/일괄 다운로드 표시.
8. 사용자/관리자 라이브러리에서 `card-news` 필터와 제목 검색으로 PNG 5개와 ZIP 1개가 이 프로젝트에 연결된 것을 각각 HTTP 200 응답으로 확인.
