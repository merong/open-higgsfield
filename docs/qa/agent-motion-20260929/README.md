# 작업 진행 모션 개선

2026-09-29. 기존 제목 shimmer와 세 줄 skeleton을 작업 패널 전반의 모션으로 교체했다.

- 기존 스튜디오의 표면·텍스트·라임 강조 토큰과 글꼴을 사용한다.
- 문서 작성, 기획 연결, 검수 스캔, 부분 수정, 이미지, 음성의 6개 모션을 현재 작업 단계에 연결한다. 장식용 모션이며 하위 작업 완료나 완료율을 뜻하지 않는다.
- 랜딩/상품 상세에서는 승인된 실제 섹션 제목을 작업 대상으로 표시한다. patch/refine은 실제 대상 ID로 제한한다.
- 최근 서버 이벤트를 패널 하단에 바로 표시하며, 이전 이벤트는 접어서 볼 수 있다.
- 대기 상태에서는 작업 장면의 모션을 멈춘다. reduced motion에서는 패널의 모든 애니메이션을 제거한다. 모션 도형과 타이머는 보조기술 낭독에서 제외한다.
- 타이머는 마운트 이후 시작하여 서버/클라이언트 초기 출력의 시간 차이를 없앤다.

## 검증

실제 AgentThinking 컴포넌트를 임시 개발 전용 페이지에서 렌더링하여 Ego Lite TaskSpace 26으로 확인했다. 검증용 고정 상태이며 공급자 호출·유료 생성·운영 프로젝트 변경은 없었다. 임시 페이지는 검증 후 제거했다.

- [데스크톱 1280px](desktop.png), [모바일 390px](mobile.png): 가로 넘침 없음. 두 화면을 직접 시각 확인했다.
- 작성 단계에서 `console.error` 0개. 문서·패널 애니메이션 실행 확인.
- 검수 단계의 스캔 표시 확인. `prefers-reduced-motion: reduce`에서 실행 중 애니메이션 0개.
- [단계별 상태 기록](states.json): 기획·이미지·음성·부분 수정 모션과 대기 중 장면 애니메이션 정지 확인.
- TypeScript 검사 및 diff 공백 검사 통과. 서비스 동작 변경이 없는 공통 UI 수정으로 전체 AI E2E는 반복하지 않았다.
