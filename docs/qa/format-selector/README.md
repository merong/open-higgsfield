# 제작 기능 선택 UI 통일

검증일: 2026-09-21 · 로컬 개발 서버 `http://127.0.0.1:3000`

## 적용

- ‘템플릿으로 시작’ 화면의 이미지 카드를 공통 `FormatSelector`로 추출했다.
- 프로젝트 목록, 네 가지 기능의 AI/직접 구성 시작 화면, 템플릿 시작 화면, 진행 중인 워크플로우, 프로젝트 편집기에서 같은 컴포넌트를 사용한다.
- 썸네일, 제목, 설명, 출력 형식, 선택 테두리 및 ‘선택됨’ 배지를 통일했다. 목록의 프로젝트 필터는 제작 기능 선택과 목적이 다르므로 유지했다.
- 기능별 메타데이터는 `src/projects/formats.ts`, UI는 `src/editors/format-selector.tsx`, 스타일은 `src/editors/format-selector.css`에서 관리한다. 기존 목록/축약형 선택 카드 스타일과 워크플로우의 선택 카드 숨김 규칙은 제거했다.
- 다른 기능으로 전환할 때 현재 작업의 워크플로우 URL 매개변수를 제거한다. 카드뉴스 템플릿에서 템플릿을 지원하지 않는 기능으로 전환하면 AI 제작으로 시작한다.
- 시작 방식은 URL에도 반영해 새로고침 시 유지한다. 이미 선택한 기능을 다시 누르면 입력을 초기화하지 않는다.
- 편집기에서 다른 제작 기능을 선택하면 저장 완료 후 새 프로젝트 화면으로 이동한다. 기존 프로젝트의 포맷을 변환하지 않는다. 저장 실패 시 현재 편집기에 머물며 오류를 표시한다.
