## 최종 결과

기존 ‘초보 식집사를 위한 첫 식물 가이드’의 원고를 유지한 후속 제작으로 검증했다. 이미지는 1/5장에서 **5/5장**으로 증가했다. 먼저 빈 카드 4장만 일괄 생성했고, 검수에서 지적된 2·5장의 이미지와 배치를 보강했다. 전체 5장의 ID·종류·제목·본문·머리말·CTA를 이전 완료 JSON과 비교하여 **모두 동일**함을 확인했다.

| 평가 항목 | 통과 | 확인 필요 | 수정 필요 | 최종 평가 |
| --- | ---: | ---: | ---: | --- |
| 텍스트 매칭 | 4/5 | 1/5 | 0 | 4장 사진의 잎 구성이 산세베리아·ZZ 두 종만을 명확히 나타내는지 사람의 확인 필요 |
| 타이포그래피 | 5/5 | 0 | 0 | 제목/본문 위계, 줄바꿈, 행간 확인. 360px 기준 본문 16.2px |
| 내용 검수 | 4/5 | 1/5 | 0 | 5장 반려동물 ‘접근 확인’ 문구의 구체화 여부는 사용자 선택 사항 |
| 출력 검수 | 5/5 | 0 | 0 | 관찰상 글자 잘림·누락·깨짐 없음. 브라우저 경계 검사 문제 0건 |
| 수정 원칙 | 5/5 | 0 | 0 | 원고 동일성 비교 통과. 글씨 축소 없이 이미지 비율·여백·크롭 재배치 |

이는 특정 예제의 모델 평가와 실제 PNG/브라우저 측정 결과이며 사실 정확성 또는 종 식별 보증이 아니다. 근거는 이전 실행에서 확보한 5개 출처를 재사용했다. 이번 시각 검수에서 웹을 새로 검색하지 않았다. 확인 필요 두 항목은 숨기거나 임의 교정하지 않고 결과에 남겼다. E2E에서 이 확인 사항을 읽고 확인 체크 후 로컬 파일 보관까지 완료했으며 외부 게시를 하지 않았다.

## 리뷰로 발견하고 개선한 실제 문제

1. **첫 검수 v15**: 2장 잎 형태의 식물명 대응 불확실, 본문 마지막 한 단어 줄바꿈, 5장 잡지/인쇄물 검출. 원고를 보존하는 AI 재배치와 선택 카드 이미지 구상 수정/재생성을 수행했다. [첫 검수](visual-plant-first-review.json), [2장 이전 PNG](visual-plant-first-review-02.png), [5장 이전 PNG](visual-plant-first-review-05.png).
2. **v20**: 타이포그래피는 개선됐지만 5장 생성 사진에 원하지 않은 포장물이 남았다. ‘관리 도구 정물’에서 ‘손으로 흙 상태 확인’ 장면으로 이미지 구상만 변경했다. [재검수](visual-plant-second-review.json).
3. **v24**: 2장 사진을 크게 재배치하자 강한 직사광선/화분 라벨이 드러나 본문과 충돌했다. 실제 시각 검수가 `matching:fail`로 판정했고 화면에서 완료 버튼을 차단했다. 부드러운 확산 조명의 식물 사진으로 교체했다. [차단 증거](visual-plant-blocked-review.json), [해당 PNG](visual-plant-blocked-review-02.png).
4. **v26**: 이미지 매칭 문제는 개선됐지만 14.4px 본문이 작은 편이라는 지적이 나왔다. 본문 토큰을 **4.5cqw(360px에서 16.2px)**로 높이고 마지막 카드는 설명 중심 배치로 바꿨다. 문구를 축약하지 않았다. [가독성 개선 전 검수](visual-plant-final-review.json).
5. **최종 v28**: 타이포그래피·출력·문구 보호 전 카드 통과. 위 표의 두 확인 필요 항목만 남았다. PNG 5장과 동일 버전 ZIP을 보관했다.

## 실제 출력

아래는 HTML 캡처가 아니라 다운로드 ZIP에서 꺼내 직접 확인한 최종 PNG이다.

- [1장 · 표지](visual-plant-completed-01.png)
- [2장 · 식물 이미지/배치 수정](visual-plant-completed-02.png)
- [3장 · 스파이더 플랜트](visual-plant-completed-03.png)
- [4장 · 두 식물 사진 확인 필요](visual-plant-completed-04.png)
- [5장 · 손으로 흙 상태 확인](visual-plant-completed-05.png)

전부 1080×1350. ZIP 6,994,253bytes, `01.png`~`05.png`, `caption.txt`, `project.json` 총 7개. 개별 PNG 다운로드 5개 모두 HTTP 200 / image/png이며 ZIP의 파일 바이트와 일치한다. 서버는 PNG CRC/압축 픽셀/규격, 프로젝트 버전, 검수 ZIP SHA-256을 확인한다.

## UI 및 상태 검증

- 인앱 브라우저에서 일괄 생성, 카드 선택, 실제 썸네일, 문구 보호 재배치, 이미지 구상 저장/생성, 사진 배치/크롭, 검수 보고서, 완료 차단, 확인 체크, 최종 보관/다운로드를 실행했다.
- 390px viewport에서 document/body 폭 390px, 가로 넘침 없음. 카드 미리보기 폭 354px에서 본문 15.93px. 5개 썸네일 이미지 로드 성공. 모바일 검증 후 viewport 설정을 복원했다.
- 최종 파일과 별도로 360px 환산 글자 크기, 제목/본문 누락, 텍스트 경계·하단 영역, 폰트·이미지 로드를 검사했다. 실제 기기 전체 조합을 시험한 것은 아니다.
- 서버 실행 유지. 이미지 비용은 일괄 요청 전에 표시하고 사용자가 승인한 누락 카드만 처리한다. 검수는 실행에 고정된 관리자 모델/effort를 사용한다.
- 호출: OpenAI **7회**(배치 수정 1 + 원고 검수 1 + 실제 PNG 검수 5), 이미지 생성 **8회**(빈 카드 4 + 수정 이미지 4). 앱 크레딧 **539 → 506**, 제작 1 + 이미지 32. OpenAI 제공업체 사용료는 별도이며 공급자 청구 금액은 측정하지 않았다.
