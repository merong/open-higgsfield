# 제품 상세 페이지 검증

2026-09-21 · 로컬 개발 환경 · 서버 http://127.0.0.1:3000

## 구현
- 네 번째 프로젝트 형식 `product-detail`. AI 협업과 무료 직접 구성 지원.
- 상품명·카테고리·가격·옵션·규격·사용법·배송·반품 정보의 검증 및 계정별 저장.
- 상품 소개, 구매 포인트, 디테일, 사용법, 규격, 배송·반품, FAQ, 구매 연결 섹션.
- 고객·판매 포인트 확인 → 기획 승인 → 원고 작성·검수 → 선택 섹션 수정 → 이미지 확인 적용 → 편집기 인계.
- 기존 이미지 큐, 모델·프롬프트 수정, shimmer, 서버 보관 및 명시적 확인 적용을 재사용.
- 이미지 1개일 때 모달은 사진과 설정을 나란히 배치. 모바일은 한 열.
- 상품 가격·옵션은 구매 요약, 규격은 정의 목록, 배송·반품은 정책 안내에 확정 정보 그대로 표시. AI 검수에도 이 출력 정보를 전달.
- 프로젝트·내 라이브러리·관리자 필터, 도움말, 모바일·데스크톱 미리보기와 HTML ZIP 연결.
- 기존 JSON 프로젝트 문서와 페이지 워크플로우 테이블을 확장하여 저장. 형식별 진행 중 작업 조회를 분리하고 원본 랜딩 흐름을 유지.

## 실제 AI 및 브라우저
- 프로젝트 `3d7cbe3a-f5e9-4683-86ae-4c168e031731`: **데모 · 모닝 세라믹 머그 상세 페이지**.
- 워크플로우 `4b120bea-6162-4856-acde-0adaee06739b`: completed. 편집기로 인계한 뒤 재진입 가능.
- 저장된 `gpt-5.6-terra`로 8회의 의도·기획·작성·검수·선택 수정 호출. 요청한 7개 섹션, 대표 이미지 1장 계획 반영.
- 28,000원 / 300 ml / 아이보리·차콜 / 머그 1개 / 손세척 / 입력한 데모 배송·반품 정책 보존.
- 초기 원고 검수에서 근거 없는 사용감 표현을 지적했고 해당 섹션을 수정. 별도 상품 요약의 가격을 원고 누락으로 판정한 문제는 검수 입력과 지침을 보완하여 해결.
- 이미지 관련 의견(두 개의 머그로 보이는 구성, 미확인 표면 마감)은 모달 프롬프트에서 단일 머그·색상 옵션 견본으로 조정하고 마감 지시를 제거. 실제 생성 후보를 직접 확인 후 적용. 이전 이미지 의견은 작업 이력에 남아 있음.
- Soul 2로 이미지 1장 생성 성공. 작업 `e6002fdb-a95f-4a6f-93d2-9bc42f7f3b68`, 보관 에셋 `0b7e638d-5371-470f-bdc2-5e9805399249`. 확인 전 자동 적용되지 않고 버튼으로 적용됨.
- 실제 앱 크레딧 **5 사용**: 원고 1 + 이미지 4. 관리자 잔액 333 → 328.
- 데스크톱 미리보기 1120px, 모바일 미리보기 375px: 가로 넘침 없음, 보관 이미지 정상 로드.
- HTML ZIP을 UI에서 생성·서버 보관하고 다운로드 확인. `product-detail-demo.zip`: index.html, project.json, 이미지 1개, 로컬 글꼴과 라이선스 포함. HTML에 임시 이미지 안내 또는 앱 전용 이미지 URL 없음.
- ZIP을 풀어 임시 로컬 서버에서 실제 출력 검증. 390px 모바일에서 이미지 정상 로드, 가로 넘침 없음, 구매 안내 내부 앵커 이동 성공. 임시 검증 서버는 종료하고 앱 서버는 유지.
- 무료 직접 구성: 상품명만 입력해 7개 섹션 생성, 상품명을 사용하는 이미지 프롬프트 확인. 규격을 32 × 22 cm로 수정하고 새로고침해 저장 유지 확인.
- 도움말의 실제 편집 화면 PNG 정상 로드, 새 제작 화면으로 연결 확인. 390px 제작 유형 카드는 2열로 줄바꿈 확인.

## 범위와 남은 기록
출력물은 판매처 URL로 연결하는 정적 상세 페이지다. 장바구니·결제·주문 서버나 자동 배포는 포함하지 않는다. 샘플의 가격·정책과 사진은 기능 검증용 데모이며 실제 판매 상품을 보증하지 않는다.

임시 직접 구성 QA 프로젝트 `aef86573-610f-4159-b561-6fe948ec7127`, `fe64c9ed-4bff-468b-a19e-b93639180873`는 그대로 남아 있다. 자동 승인 검토가 명시적 정리 승인 부재를 이유로 삭제·보관을 거절하여 정리하지 않았다. 최종 AI 데모 및 기존 사용자 프로젝트는 보존했다.
