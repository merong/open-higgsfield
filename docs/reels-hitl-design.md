# 숏폼 · 릴스 사용자 참여 제작 설계

2026-09-20. 원본: [첨부 가이드](shortform-reels-human-in-the-loop-guide.md). 식물은 평가 예시이며 제품 로직은 범용이다.

## 구현 방향

주제 → 필요한 목적 질문 → 근거 조사 → 대본·콘티 승인 → 대표 장면 생성 및 실제 MP4 샘플 → 샘플 승인 → 나머지 장면 → 초벌 MP4 → 구간 수정 → 최종 재생 확인 → 파일 보관. 질문·도구 대기는 모델 호출 없이 DB에서 복원한다. 비용이 드는 자산 생성은 명시적인 견적 버튼으로 실행한다.

기존 카드뉴스 작업은 유지하고 `reel_workflows` / `reel_workflow_versions`를 추가한다. 프로젝트·라이브러리·관리자 조회·크레딧·Higgsfield 비동기 작업은 기존 서비스를 사용한다. 서버가 소유권·리비전·응답 ID·잠금·예산을 검증한다. 외부 작업 접수 불명은 자동 재결제하지 않는다. 취소·구버전 결과는 최신 장면을 덮어쓰지 않는다.

## UI / UX

기존 dark/lime 토큰 유지: 바탕 #0a0a0b, 패널 #151719, 주문구 #edefef, 액션 #d1fe17. 화면은 실제 프로젝트 DS CSS 변수를 참조한다. Pretendard는 본문·제목, 시간코드에는 tabular-nums를 사용한다.

```text
제작 명세  30초 · 9:16 · 화면 문구 / AI 음성       [중단]
┌ 제작 대화 / 승인 ──────────┬ 세로 플레이어 ┬ 장면 편집 ────┐
│ 실제 진행 이벤트          │  재생·무음     │ 화면 문구       │
│ 핵심 질문 / 추천          │  안전영역     │ 발화·이미지 구상 │
│ 대본·콘티 승인            │              │ 문구·길이 잠금   │
└──────────────────────────┴──────────────┴────────────────┘
시간축: [00:00 훅][00:06 전개][00:12 변화][00:24 마무리]
       영상       발화(실측)       자막(정렬)       음악
[대표 샘플] → [샘플 승인] → [전체 제작] → [출력 검수] → [파일]
```

고유 요소는 ‘초 단위 콘티’다. 각 장면에 실제 시간 구간·자산·발화 상태를 함께 표시하고, 현재 장면의 수정에만 비용과 재작업 범위를 안내한다. 모바일은 대화 → 플레이어 → 장면 설정 순서로 접는다. 생성 중 장면 수/도구 상태를 표시하며 가짜 진행률·내부 사고 과정은 표시하지 않는다.

## 출력·음성·검수

- 명시적 30fps 정수 프레임 `[start,end)` 시간축, 15/30/60초 목표. 한국어 단일 언어, 1080×1920 H.264 MP4/AAC 서비스 프리셋.
- 브라우저에서 번들 Pretendard 폰트로 원문을 측정하고 투명 PNG 타이포 레이어 생성. 서버 FFmpeg는 소유한 이미지/영상·음성·레이어만 합성하며 외부 주소를 FFmpeg에 전달하지 않는다.
- 이미지 모션, 업로드 영상, 선택적 Higgsfield 영상. 원본 영상의 소리는 사용하지 않으며 내레이션·업로드 음악을 별도 트랙으로 관리한다.
- 선택적 OpenAI `gpt-4o-mini-tts` 음성, `whisper-1` 실제 발화 타임스탬프. 대본과 전사 차이를 숨기지 않는다. 발화가 길면 잠긴 문구를 줄이거나 속도를 올리지 않고 시간 재배분/명시적인 길이 변경을 요청한다.
- 자막 스타일 수정은 시각 합성만 무효화한다. 문구 수정은 해당 장면 음성/정렬을 무효화하고 시각 원본은 보존한다. 자산 교체는 문구·음성을 보존한다. 샘플과 완성본은 버전별 보관한다.
- 전체 파일 디코딩, 길이/프레임/트랙/규격·빈 프레임 탐지와 오디오 피크 검사를 수행한다. 대표 프레임 AI 검수는 보조이며 ‘전체 영상을 보았다’고 표시하지 않는다. 최종 전체 재생·음성 청취·무음 가독성은 사용자 확인으로 기록한다. 필수 오류·잠금 위반·글자 영역 초과는 완료를 막는다.
- MP4, 커버 PNG, 실제 정렬 SRT/VTT(음성 사용 시), 게시문, 재편집 JSON, 검수 보고서를 ZIP으로 제공하고 내 라이브러리 및 관리자 결과에 연결한다. SNS 게시 권한은 포함하지 않는다.

## 검증

메모리 DB로 권한·중복·리비전·늦은 결과·취소·비용·잠금·시간 충돌·부분 수정·검수 게이트 테스트. 실제 앱에서는 식물 30초 예시를 진행하여 샘플 승인, 전체 재생, 자막 변경 후 음성 재사용, 새로고침 복원, 다운로드 파일을 확인한다. 실제 제공업체 호출과 테스트 대역 결과를 구분하여 QA 기록을 남긴다.

## API 근거

[OpenAI 음성 생성](https://developers.openai.com/api/docs/guides/text-to-speech), [실제 음성 전사·타임스탬프](https://developers.openai.com/api/docs/guides/speech-to-text). 관리자에 저장된 텍스트 모델/effort는 유지하며 음성 도구 모델만 별도 명시한다. AI 생성 음성임을 제작 화면에 표시한다.
