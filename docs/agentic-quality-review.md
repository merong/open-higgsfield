# 전체 기능 점검과 에이전틱 품질 개선

점검일: 2026-09-22 · 로컬 개발 서버 `127.0.0.1:3000`

후속 검증: [2026-09-27 실제 이미지·PNG·MP4·HTML 출력 평가](agentic-quality-evaluation-20260927.md). 실제 결과에서 발견한 구도·검수 한계와 기획 응답 복구 개선을 별도로 기록했다.

## 이번 변경

- 네 제작 포맷의 원고 검수를 **의도, 사실·원문, 흐름·차별성, 이미지 구상, 전달 밀도**로 구조화했다. 실제 화면을 보지 않은 원고 검수는 픽셀·재생 검수라고 표현하지 않는다.
- 랜딩·제품 상세와 릴스에 **초안 → 독립 검수 → 지적된 항목 보정 → 재검수**를 연결했다. 카드뉴스의 기존 루프에도 같은 기준과 이력을 추가했다. 오류가 없으면 추가 보정을 하지 않으며 최대 두 번으로 제한한다.
- 사용자 지정 수정 범위를 넘지 않는다. 확정 문구, 원본 에셋, 상품 정보, CTA, 릴스 길이를 보호한다. 정보 부족·취향·이미지 교체가 필요한 사항은 사용자 확인 대상으로 남긴다.
- Thinking 패널에 실제 단계, AI 호출 횟수, 경과 시간, 점검 대상, 최근 작업 메시지를 표시한다. shimmer는 제목과 준비 영역에 적용한다. 진행률을 만들어 내거나 비공개 사고 과정을 표시하지 않는다. 이미지 추천·글꼴 추천·출력 작업에도 연결했으며 움직임 줄이기 설정을 지원한다.
- 공개 원고에 촬영·배치 메모가 섞이지 않도록 생성·검수 지시를 분리했다. 이미지 프롬프트가 있다는 사실을 실제 생성·과금으로 해석하지 않도록 했다.
- 카드 이미지 생성 시 책·노트의 일괄 금지 및 가로 헤더 구도 강제를 제거했다. 실제 주제에 필요한 소품과 카드의 full/split 배치를 존중한다. 릴스의 책·노트 일괄 금지도 해제했다.

## 실제 응답에서 발견하고 수정한 사항

현재 등록된 `gpt-5.6-terra`, effort `low`를 그대로 사용했다. 모델/키 설정은 변경하지 않았다.

1. **제작 메모가 고객용 설명에 노출됨**: 초기 제품 원고에는 “얼굴보다 손과 차를 마시는 행동에 시선을 두어”라는 촬영 지시가 있었다. 생성·검수 기준을 강화한 최종 결과는 “300ml 용량으로 일상의 차 한 잔을 담습니다”처럼 고객용 문장으로 바뀌었다. 한 사례의 개선이며 모든 주제의 품질 향상을 보장하는 평가는 아니다.
2. **불필요한 자동 수정**: 검수 모델이 ‘유료 이미지 생성 안 함’과 ‘이미지 구상 프롬프트 존재’를 혼동했다. 구상과 실행을 구분하고 이미지 계획 변경은 확인 사항으로 분류하도록 보완했다.
3. **보호 필드 검증 오류**: 위 지적으로 모델이 빈 이미지 프롬프트를 반환하면서 보정이 중단됐다. 자동 원고 보정에서는 모델이 반환한 보호 필드를 먼저 검증하는 대신 저장된 프롬프트·시간·역할을 유지하도록 고쳤다. 빈 프롬프트 및 잘못된 시간값을 반환하는 회귀 시나리오도 통과했다.
4. **범위 밖 카드 보호**: 1장만 수정한 실제 검수에서 2·3장의 추가 지적이 나왔으나 자동으로 수정하지 않고 확인 사항으로 남겼다.

최종 제품 검수에는 실제 이미지 생성 전 디테일 확인이 필요하다는 attention 1건이 남았다. 오류가 없다는 모델 판정과 게시 가능한 완성품은 구분해야 한다.

## 다음 개선 우선순위

1. **랜딩·제품 상세의 최종 화면 검수**: 원고 루프와 별도로 실제 HTML을 360/768/1280px에서 렌더링하고, 글자 넘침·이미지 크롭·CTA·이미지와 설명의 대응을 검수하는 단계가 필요하다. 이번에는 원고 품질 루프를 구현했다.
2. **장면 간 피사체 일관성과 영상 시간축 평가**: 참고 이미지와 스타일 기준을 더 강하게 연결하고, 릴스 중앙 프레임 검수 외에 전환 전후·동작·음성 흐름을 평가해야 한다. 현재 출력 검수는 전체 재생을 했다고 주장하지 않는다.
3. **품질 평가 예제 묶음**: 정보형, 상품형, 뉴스형 등의 확정 입력·좋은/나쁜 예제·사용자 채택 결과로 개선 전후를 반복 비교해야 한다. 특히 입력 사실이 부족한 경우에는 불필요하게 긴 원고 대신 필요한 정보만 추가로 묻는 방향이 좋다.
