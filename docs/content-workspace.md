# 콘텐츠 제작 워크스페이스

2026-09-19. 기존 스튜디오와 디자인 시스템 0.2를 연결한 카드뉴스·릴스·랜딩 편집기.

## 실행

```sh
corepack pnpm install --frozen-lockfile
cp .env.example .env.local
corepack pnpm dev
```

http://localhost:3000/projects 에서 가입 후 시작한다. 가입 초기 크레딧은 50이다. 템플릿 구성안, 업로드, 편집, 파일 출력은 생성 크레딧 없이 사용할 수 있다. 로컬 DB는 `.data/postgres`에 저장되며 브라우저를 닫거나 서버를 재시작해도 유지된다. 이 디렉터리는 Git에 포함하지 않는다.

운영에서는 `DATABASE_URL`에 PostgreSQL을 연결한다. 운영 모드에서 DB 설정이 없으면 요청을 거절한다. DB 스키마는 최초 연결 시 생성하며 `assets.byte_size` 추가는 재실행 가능하다. 운영 서비스의 DB 권한·백업·연결 풀 설정은 배포 환경에 맞춰 관리한다. Vercel 등 임시 파일시스템 환경에 로컬 PGlite를 배포하지 않는다.

- 카드뉴스: 7개 템플릿, 4개 스타일, 4:5/3:4/1:1/9:16. 너비 1080 PNG 단일 또는 전체 ZIP, 캡션, 원본 JSON.
- 릴스 AI와 함께 제작: [사용자 참여 워크플로우](reels-hitl-design.md), 대본 승인·대표 샘플·장면별 생성·AI 음성/실제 정렬 자막·MP4 1080×1920·검수·ZIP. 서버에 FFmpeg/ffprobe가 필요하다.
- 릴스 직접 구성하기: 9:16 장면, 이미지/영상 배경, 시작 위치와 장면 길이, 순차 미리보기, 반복 배경음, WebM 720×1280 합성, SRT. 원본 영상 소리는 제외하며 짧은 영상은 마지막 프레임을 유지한다.
- 랜딩: hero/features/story/testimonial/pricing/faq/cta, 데스크톱/모바일 미리보기, CTA 링크, 반응형 HTML ZIP. 글꼴·라이선스·이미지를 함께 보관해 독립적으로 호스팅할 수 있다. 입력 문구는 HTML 이스케이프하고 링크 스킴을 제한한다.
- 완성된 ZIP/WebM/PNG는 계정 파일로 보관하고 저장 링크를 제공한다. 서버 보관 실패 시 현재 탭의 로컬 파일 링크를 제공한다. 파일당 50MB, 계정당 500MB이며 동시 업로드도 한도에 포함한다.
- 카드와 직접 구성하기 릴스는 디자인 시스템의 실제 슬라이드 DOM을 같은 렌더러로 미리보기/출력한다. 긴 문구가 출력 영역을 넘으면 오류를 보여 준다. 목록 5개, 비교 2개를 초과한 내용도 저장 오류로 안내한다.

## 생성 API와 크레딧

관리자가 `/admin/settings`에 Higgsfield `id:secret`을 등록하면 모든 사용자의 생성에 공용 키를 적용한다. 키는 암호화하여 서버에 저장하며 클라이언트로 반환하지 않는다. 등록된 키가 없으면 `HF_OPERATOR_API_KEY`와 선택적인 `HF_API_BASE_URL` 설정을 사용한다. 기존 모델 카탈로그와 요청 매핑/묶음 폴링을 재사용한다. [관리자 설정 안내](admin-settings.md)를 참고한다. 생성 전 예상 크레딧을 확인한다. 기본 내부 단가는 이미지당 4, 영상 초당 8이며 환경 변수로 변경한다. 공급자의 실제 과금표를 의미하지 않는다.

`ANTHROPIC_API_KEY`와 `OUTLINE_MODEL`을 설정하면 1크레딧 AI 구성안을 선택할 수 있다. [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create)를 호출하고 응답을 공통 프로젝트 스키마로 검증한다. 설정이 없으면 무료 템플릿 초안만 제공하며 AI 작성이라고 표시하지 않는다.

생성 요청은 사용자 행 잠금 → 중복 요청 키 확인 → 동영상 최소 잔액(50 초과)·견적 비용 검사 → 잔액 차감·원장 기록 → 공급자 접수 순서다. 완료는 예약 확정, 실패/NSFW/취소/빈 결과는 한 번만 환불한다. 접수 응답을 잃은 경우에는 이미 공급자 비용이 발생했을 수 있으므로 `unknown`으로 보관하고 자동 재접수하지 않는다. 같은 키와 다른 내용의 재요청은 거절한다. 서버 중단으로 남은 `submitting`도 관리자 확인 대상이다.

```sh
# 가입된 사용자에게 수동 충전 / 관리자 부여
corepack pnpm admin --email owner@example.com --credits 50
corepack pnpm admin --email owner@example.com --admin
# 공급자 대시보드에서 실제 접수를 확인한 후 요청 연결
corepack pnpm admin --job JOB_ID --request-id PROVIDER_REQUEST_ID
# 미접수 또는 실패가 확인된 예약 환불
corepack pnpm admin --refund-job JOB_ID
```

로컬 PGlite는 한 프로세스만 사용한다. 로컬 관리자 CLI를 실행할 때는 개발 서버를 중지하고 실행 후 재시작한다. PostgreSQL을 사용하는 운영 CLI에는 같은 `DATABASE_URL`을 제공한다. CLI는 `.env.local`을 읽는다.

## 저장·권한

- scrypt 비밀번호 해시, 무작위 세션 토큰의 SHA-256 해시만 DB 저장, HttpOnly/SameSite 쿠키, 운영 Secure 쿠키, 14일 세션.
- 모든 프로젝트·파일·생성 조회에 소유자 검사. 프로젝트 버전 충돌은 409로 저장을 중지하며 JSON 백업 후 새로 불러오도록 안내한다. 자동 저장은 직렬화해 저장 중 추가 편집을 보존한다.
- 관리자 권한은 DB 플래그다. 이메일만으로 관리자가 되지 않는다. 수동 충전은 원장에 사유를 남긴다.
- API 변경 요청은 같은 출처를 검사하고 로그인 시도 횟수를 제한한다. 관리자 접근은 커스텀 서버가 서명한 소켓 접속 IP로 검사하며 클라이언트의 `X-Forwarded-For`를 신뢰하지 않는다. 현재 직접 접속하는 Node 서버용이며 리버스 프록시 배포 전에는 신뢰 프록시 정책을 별도로 구현해야 한다.
- 기본 업로드는 인증된 DB 파일이다. 선택적으로 Vercel Blob을 연결하면 생성 공급자 입력에 필요한 **공개 URL**로 업로드한다. 생성 입력에는 공개 HTTPS 주소가 필요하다. Blob에 올리는 자료의 공개 범위를 운영 정책에 맞춘다.
- 생성 결과는 계정 에셋으로 복사를 시도한다. 공급자의 CORS/다운로드 제한으로 복사가 실패하면 원래 URL과 안내를 유지하므로 장기 보관을 보장하지 않는다.
- 기존 스튜디오 갤러리/즐겨찾기/업로드 이력은 기존 브라우저 IndexedDB 구조를 유지한다. 새 프로젝트 및 과금·생성 내역은 서버 계정에 저장된다.

## 구조와 확장

`src/projects/formats.ts`에 포맷과 템플릿, `types.ts`/`validation.ts`에 문서 계약을 둔다. `src/editors`는 공통 편집기와 미리보기, `src/render`는 파일 출력, `src/service`는 인증·DB·크레딧·공급자 처리를 담당한다. `src/app/api/workspace/[[...path]]/route.ts`가 서비스 경계다.

디자인 패키지는 `vendor/design`에 0.2 빌드를 보관해 이 저장소만으로 설치할 수 있다. 원본은 상위 워크스페이스 `design/`이다. UI 토큰/DS 컴포넌트를 재사용하며 원본 `openhiggsfield.css`는 수정하지 않았다. 패키지 갱신은 원본 디자인 테스트/빌드 후 `corepack pnpm design:sync`로 수행한다.

향후 포맷 추가는 레지스트리·스키마·미리보기·출력 구현을 함께 추가한다. 결제 PG, 이메일 인증/비밀번호 복구, 백그라운드 영상 렌더 워커, MP4 출력, 랜딩 배포/커스텀 도메인은 아직 제공하지 않는다. 현재 WebM은 브라우저의 실시간 MediaRecorder 출력으로 탭을 계속 열어야 하며 정확한 프레임 타이밍/탐색 메타데이터는 브라우저에 따라 달라진다.

## 검증

```sh
corepack pnpm test
corepack pnpm exec tsc --noEmit
corepack pnpm build
```

자동 테스트는 실제 메모리 PGlite와 주입형 공급자로 계정/세션, 3개 포맷 CRUD, 소유권, 버전 충돌, 입력 검증, 중복/동시 과금, 실패 환불, 접수 불확실성, AI 응답 검증 및 파일 한도를 확인한다. 외부 유료 API를 호출하지 않는다.

로컬 인앱 브라우저에서 가입·로그인, 3개 포맷 생성/수정/재접속, 사진 선택, 영상/오디오 업로드 및 출력 파일 준비를 확인했다. `docs/qa/`에는 PNG/ZIP/WebM 및 실제 화면 증거를 보관한다. 영상 검증은 1초 트림된 4초 테스트 클립 + 이미지 + 텍스트를 2초씩 합성했으며 VP9 720×1280, Opus 약 6초를 확인했다. 현재 Chromium 출력의 마지막 Opus 패킷과 가변 프레임 타임스탬프에 FFmpeg 경고가 있어 재인코딩이 필요한 유통 환경에는 별도 변환이 필요하다.

추가로 등록된 Higgsfield 키를 사용해 이미지 3건·영상 1건의 실제 생성과 PNG/WebM/HTML ZIP 출력을 확인했다. 자세한 기록은 [관리자 설정 검증](admin-settings.md)에 정리했다. 운영 PostgreSQL 연결, 결제, 외부 호스팅/게시 및 배포는 이번 로컬 검증에 포함하지 않는다.

관리자는 `/admin` 대시보드와 왼쪽 메뉴로 사용자·프로젝트·생성 내역·전체 에셋·크레딧·API 환경설정을 관리한다. 새 메뉴의 조회 범위와 검증 기록은 [관리자 사이드바 안내](admin-settings.md#관리자-사이드바와-운영-페이지)에 정리했다.

기능별 사용 안내는 `/help`에서 제공한다. 실제 화면 이미지와 이용 방법을 문서별로 나누고, 제작 기능·API 연결에만 워크플로우 그림을 표시한다. [도움말 센터 구성](help-center.md)을 참고한다.
