# 콘텐츠 목적에 맞는 타이포그래피 선택

## 목표

카드뉴스·랜딩·제품 상세에서 폰트를 콘텐츠의 전달 방식으로 선택한다. 기존 문구는 유지하며 AI가 기획 단계에 3가지 조합과 이유를 제안한다. 사용자는 실제 제목·본문·숫자로 비교하고 제목/본문/영문 강조 글꼴과 실제 지원 굵기를 바꿀 수 있다. 초안과 일반 편집기에서도 변경 가능하다.

## 화면

기존 앱의 canvas #0a0a0b, panel #151719, raised #1a1d1f, text #edefef, secondary #a8aeaf, accent #d1fe17 토큰을 유지한다. UI는 현재 본문 글꼴을 사용하고, 콘텐츠 견본만 선택 글꼴로 렌더한다. 특징은 사용자의 같은 문구를 나란히 비교하는 작은 서체 견본이다. 모바일에는 한 열로 표시한다.

```
글꼴로 메시지의 표정을 정해요          [AI 추천 다시 받기]
[추천 1: 실제 제목 / 실제 본문] [추천 2] [추천 3]
추천 이유 · 제목의 강조 / 본문의 가독성 / 작은 화면 주의점
제목 [한글 폰트] [굵기]  본문 [폰트] [굵기]
영문 제목·숫자 [폰트] [굵기]
[실제 문구 미리보기]   [이 글꼴 적용]
```

6개 시작 조합: 명료한 정보, 기술과 전문성, 강한 메시지, 프리미엄, 자연과 감성, 밝고 친근함. 한글 10종·영문 10종을 등록한다. 추천은 분위기와 목적뿐 아니라 문구 길이, 숫자 비중, 매체의 읽기 크기를 고려한다. 긴 설명에 제목용 폰트를 추천하지 않는다. 기본 조합은 AI 추천으로 표시하지 않는다.

## 구현과 보호

- 원본 가이드: `docs/free-webfont-guide.md`.
- 공식 배포 파일을 버전 고정하여 SHA256·라이선스·실제 cmap·굵기/축을 기록한다. TTF는 글리프를 줄이거나 수정하지 않고 WOFF2로 무손실 압축한다. 압축 전후의 모든 SFNT 테이블이 같은지 검증하며, 체크섬과 압축 표시 비트만 제외한다. 원본과 압축 파일의 해시를 함께 기록하고 필요한 파일만 로드한다.
- 프로젝트에 역할별 폰트 ID·실제 굵기·조합 버전을 저장한다. 기존 프로젝트는 명시적 변경 전 기존 출력 유지. 새 추천이 사용자 확정 선택을 덮어쓰지 않는다.
- 기획 모델 출력에는 허용된 조합 ID와 추천 이유·주의점을 받는다. 서버가 검증한다. 선택은 실행 버전과 함께 저장되고 카드 출력 검수는 무효화하여 새 폰트로 다시 검사한다.
- 카드 SVG/PNG와 페이지 iframe/HTML ZIP은 같은 파일을 사용한다. HTML ZIP에는 사용하는 웹폰트와 라이선스·manifest를 포함한다.
- font-synthesis:none. 단일 굵기 폰트에 가짜 bold/italic을 만들지 않는다. 실제 문구의 글리프 지원을 확인하고 부족한 글자는 명시한 본문/기본 폰트로 보완하며 전체 체인에도 없으면 출력을 차단한다.
- 폰트 로딩 완료 후 줄바꿈·넘침·모바일 본문 크기를 검사한다. 문구 축약이나 자동 글자 축소는 하지 않는다.

## 검증

허용 목록/실제 굵기/라이선스·해시, 추천 응답·사용자 선택 보호·동시성·소유권, 세 포맷 저장/복원, 사용자 문구 불변, 카드 출력 검수 무효화, 실제 웹폰트 로드와 모바일 화면, PNG와 오프라인 HTML ZIP의 파일 포함을 확인한다.

## 폰트 재현

`python3 scripts/fonts/vendor-fonts.py`로 고정 버전의 공식 파일을 받고, `python3 scripts/fonts/compress-fonts.py`로 검증된 WOFF2 패키지를 만든다. fontTools와 Brotli가 필요하다. 20종 32개 파일은 압축 전 87,026,920바이트, 압축 후 23,385,764바이트이며 전체를 한 번에 로드하지 않는다.

라이선스와 출처는 `public/fonts/catalog/manifest.json` 및 각 폴더의 `OFL.txt`에 기록한다. 무손실 웹폰트 포장 기준은 [SIL OFL FAQ](https://openfontlicense.org/ofl-faq/)의 2.2.1을 참조한다. 폰트 출처는 [Pretendard](https://github.com/orioncactus/pretendard), [SUIT](https://github.com/sun-typeface/SUIT), [Google Fonts](https://github.com/google/fonts)이다.
