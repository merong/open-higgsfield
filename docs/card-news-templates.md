# 카드뉴스 시작 템플릿

`/projects/new?format=card-news`의 **템플릿으로 시작**에서 선택한다. 기존 주제 입력 방식은 **직접 구성하기**에 유지했다. 프로젝트 목록에도 진입 버튼이 있다.

| 템플릿 | 용도 | 스타일 | 구성 |
| --- | --- | --- | --- |
| 여름의 스킨케어 | 제품 소개 | 에디토리얼 | 표지 · 본문 · 체크리스트 · 사용 안내 · 마무리 |
| 처음 키우는 초록 | 실용 가이드 | 소프트 | 표지 · 빛 안내 · 체크리스트 · 인용 · 마무리 |
| 손끝에서 시작된 이야기 | 브랜드 스토리 | 에디토리얼 | 표지 · 철학 · 제작 과정 · 가치 · 마무리 |
| 주말의 나이트 마켓 | 행사 안내 | 임팩트 | 표지 · 프로그램 · 시간 · 방문 안내 · 마무리 |
| 취향으로 고르는 커피 | 비교 설명 | 시그니처 | 표지 · 추출 비교 · 취향 비교 · 실험 · 마무리 |

각 5장, 4:5. 기존 생성 예시 이미지를 활용하며 표지와 모든 장의 미리보기는 편집기와 같은 `ProjectSlide`를 사용한다. 예시 브랜드·문구·일정은 게시 전 사용자가 수정한다.

템플릿 정의는 `src/projects/card-templates.ts`에 있다. 미리보기에는 고정 ID를 사용하고, 시작할 때 프로젝트·슬라이드 ID와 시간을 새로 만든다. 기존 소유권 검증을 거치는 프로젝트 API로 저장한다. 원본 템플릿과 다른 복사본은 변경되지 않으며 크레딧과 공급자 API를 사용하지 않는다. 템플릿 관리용 새 DB 테이블이나 별도 시드는 필요하지 않다.

GitHub는 조회 당시 Today 목록에서 두 저장소를 골랐으며 순위·별표 수를 고정된 수치로 싣지 않았다. 제품의 제공 범위는 발표 시점의 조건을 명시했다. 활용 아이디어와 도입 체크리스트는 편집자 제안이다.

`news.verifiedAt`과 `news.sources`가 있는 템플릿은 상세 창에 기준일과 공식 원문 링크를 표시한다. 같은 정보는 프로젝트의 편집 가능한 캡션에 복사되어 저장·JSON·ZIP 내보내기에도 남는다. 표지와 마지막 장에도 기준일을 넣었다. 뉴스는 2026-09-20에 확인한 정적 예시이며 자동 갱신되지 않는다. 사용자가 이후 게시할 때 내용과 제공 조건을 갱신해야 한다.

각 주제의 원본 표지는 built-in image_gen으로 생성했다. 이미지 파일과 최종 프롬프트는 [이미지 제작 기록](ai-template-artwork.md)에 있다. 편집기에서 재생성할 때 사용할 주제별 배경 프롬프트도 포함한다.
