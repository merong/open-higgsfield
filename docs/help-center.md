# 기능별 도움말 센터

2026-09-19 로컬 구현.

`/help`에서 검색·분류로 문서를 찾는다. 상단 도움말 메뉴와 마이페이지·관리자 사이드바에 진입 링크를 제공하며, 프로젝트 편집기의 사용 가이드는 편집 화면을 유지하도록 새 탭에서 해당 포맷 문서를 연다.

## 문서 구성

| 분류 | 문서 | 워크플로우 그림 |
| --- | --- | --- |
| 처음 시작 | 처음 시작하기, 문제 해결과 자주 묻는 질문 | 표시하지 않음 |
| 콘텐츠 제작 | 스튜디오 이미지, 스튜디오 영상, 카드뉴스, 숏폼·릴스, 랜딩 페이지 | 표시 |
| 보관과 계정 | 내 라이브러리와 업로드, 크레딧과 생성 상태, 마이페이지 | 표시하지 않음 |
| 관리자 | 사용자와 작업 관리 | 표시하지 않음 |
| 관리자 | API 연결과 환경설정 | 표시 |

전체 12개 문서에 화면 이미지, 영역별 설명, 이용 방법, 주의할 점, FAQ, 관련 문서와 기능 바로가기를 제공한다. 실제 순서 설명이 필요한 6개 문서에만 4단계 워크플로우를 표시한다. 표시 여부는 `HelpGuide.workflow`로 명시하고, 문서 목차와 검색 카드 설명에도 같은 조건을 적용한다. 나머지 문서는 화면 설명과 번호 없는 이용 방법을 중심으로 구성한다.

도움말은 로그인 없이 볼 수 있다. 실제 계정·관리 기능에는 기존 인증·관리자 IP 검사가 그대로 적용된다. 관리자 설명은 관리자용 배지로 구분한다. 미구현 결제·알림·프로필 변경, WebM 출력, 랜딩 별도 호스팅 등의 범위도 본문에 명시한다.

## 화면과 데이터

- `src/help/guides.ts`: 문서 내용, 검색 대상, 관련 링크, 워크플로우 표시 여부.
- `src/help/workflow.tsx`: 아이콘과 연결 화살표를 포함한 SVG 그림. 큰 화면에서는 가로, 모바일에서는 세로로 표시한다. 접근성용 제목·순서 설명을 함께 제공한다.
- `src/help/help-shell.tsx`: 데스크톱 사이드바와 모바일 접이식 목차.
- `src/help/help-home.tsx`, `help-article.tsx`: 검색·분류, 이미지 확대 창, 문서 내 목차와 FAQ.
- `public/help/screens/`: 화면 예시 PNG 12장. 생성 모델로 만든 가상의 UI가 아니라 로컬 앱의 실제 화면이다.

이미지는 기존 QA용 프로젝트와 데모 계정 화면을 캡처했다. 스튜디오 2장은 기존 `docs/qa/studio-*-thumbnails.png`를 재사용했고 나머지는 현재 화면에서 캡처했다. 실제 API 키 값·비밀번호·공급자 요청 ID는 포함하지 않는다. 화면의 잔액과 콘텐츠는 테스트 예시이며 도움말 본문이 최신 기능 설명의 기준이다.

## 검증

- 로그인 없는 HTTP 조회: 도움말 12개와 이미지 12개 정상 응답, 워크플로우 6개만 표시, 관련 문서 연결, 존재하지 않는 문서 404. `docs/qa/help-http.json` 참조.
- 브라우저: 검색·빈 결과·분류 초기화, 이미지 확대 및 닫기, FAQ 펼치기, 마이페이지 도움말의 워크플로우 미표시, 카드뉴스의 워크플로우 표시.
- 모바일 390px: 접이식 목차, 세로 워크플로우, 가로 넘침 없음.
- 프로덕션 빌드와 TypeScript 검사로 정적 도움말 경로를 확인한다. 생성 API 호출이나 크레딧 지급은 수행하지 않는다.
