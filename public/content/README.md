# Sample artwork

`pool-editorial.jpg` and `sage-still-life.jpg` are original generated sample artwork prepared for this workspace's design system. They are copied from `design/public/images` and are optional starting assets, not user or brand photography.

The UI and exported landing bundle use unmodified Pretendard Variable 1.3.9 from the design workspace's `pretendard` npm package. Copyright and SIL Open Font License are included in `public/fonts/OFL-Pretendard.txt`; upstream: https://github.com/orioncactus/pretendard . Other preset font families use installed system fallbacks when unavailable.
